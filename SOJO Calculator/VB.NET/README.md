# SOJO Calculator (VB.NET)

This project is a simple calculator with some extra features developed in VB.NET.

![Screenshot 2026-04-20 051609](https://github.com/sorjoh/SOJO-Portfolio/blob/main/SOJO%20Calculator/VB.NET/Calculator.png)

## Features
- **Basic Mathematical Operations:** Addition, subtraction, multiplication, and division.
- **Extra Functions:** Percentage calculation, square and cube root, power, pi, modulus, reciprocal and random number generator.
