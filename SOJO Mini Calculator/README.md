# SOJO Calculator

This project is a simple mini calculator with basic mathematical operations currently developed in VB.NET, C#.NET and Java.

The layout, design and functionalities is inspired from: https://ecdn.teacherspayteachers.com/thumbitem/Calculator-Functions-Anchor-Chart-11020447-1707050000/original-11020447-1.jpg
